# renderpack

Render timestamps and pack durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/renderpack/

## Install / run

```bash
git clone https://github.com/theworker02/renderpack.git
cd renderpack
node src/cli.js
node --test
```
